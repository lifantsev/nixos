# NixOS
My personal NixOS system config, running on my apple silicon macbook m1 pro thanks to [nixos-apple-silicon](https://github.com/nix-community/nixos-apple-silicon) and [asahi linux](https://asahilinux.org/). Includes a suite of daily use tools I find useful.

## Installation

Follow the [nixos-apple-silicon guide](https://github.com/nix-community/nixos-apple-silicon/blob/main/docs/uefi-standalone.md). Then clone this flake to your system:
```sh
git clone git@github.com:lifantsev/nixos.git
```

Remember to extract the firmware blob from MacOS using `curl https://alx.sh | sh` periodically. Put the firmware file at [./config/ignore/firmware/firmware.cpio]. The firmware blob is expected by [./config/asahi.nix]. Make sure to also place the hardware configuration generated by NixOS install at [./config/ignore/hardware-configuration.nix].

Now you can build the flake:
```sh
sudo nixos-rebuild switch --flake path:/path/to/flake --show-trace
```
