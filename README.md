# NixOS

My personal NixOS system config, running on my apple silicon macbook m1 pro thanks to [nixos-apple-silicon](https://github.com/nix-community/nixos-apple-silicon) and [asahi linux](https://asahilinux.org/). Includes a suite of daily use tools I find useful.

## Installation

Follow the [nixos-apple-silicon guide](https://github.com/nix-community/nixos-apple-silicon/blob/main/docs/uefi-standalone.md). Then clone this flake to your system:
```sh
git clone git@github.com:lifantsev/nixos.git
```

Remember to extract the firmware blob from MacOS using `curl https://alx.sh | sh` periodically. Put the firmware file at `./config/ignore/firmware/firmware.cpio`. Make sure to also place the hardware configuration generated by NixOS install at `./config/ignore/hardware-configuration.nix`.

Now you can build the flake:
```sh
sudo nixos-rebuild switch --flake path:/path/to/flake --show-trace
```

## Documentation

Top level aesthetic config is done from [rice/](rice/). Change window gaps, font, and colorscheme [here](rice/default.nix). Colorschemes are [generated](rice/colors/.generate.sh) from [source files](rice/colors/src/).

System level [config/](config/) includes:
- [installed pkgs](config/pkgs.nix)
- [tty customization](config/tty.nix)
- [evdev level key remaps](config/keyremap.nix)
- [desktop env components](config/desktop.nix)
- [nix settings](config/default.nix)

User level config is in [home/](home/). These define configuration of user-facing programs. Notable ones include:
- [niri](home/niri/)
- [kitty](home/kitty.nix)
- [zen](home/zen/)
- [nvim](home/nvim.nix)
- [lf](home/lf/)
- [mako](home/mako.nix)

Custom packages not large enough to factor out into their own repo live in [pkgs/](pkgs/). Notable ones:
- [barless](pkgs/apps/barless/), supplies info since I don't use a bar
- [browseshell](pkgs/apps/browseshell/), open bookmarks & searches in browser
- [xioxide](pkgs/apps/xioxide.sh), index tree based bookmark structures generated [here](home/xioxide/)
- [blue](pkgs/scripts/blue.sh), manage bluetooth devices
- [net](pkgs/scripts/net.sh), manage networks & vpns
- [launcher](pkgs/scripts/launcher.sh), app launcher
- [screenrecord](pkgs/scripts/screenrecord.sh) & [screenshot](pkgs/scripts/screenshot.sh)
